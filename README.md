# 🚀 Real-Time Collaboration Platform

## 📌 Overview

This project is a full-stack **Real-Time Collaboration Platform** that allows multiple users to connect, collaborate, and manage projects efficiently. It enables team members to work together, track tasks, and communicate in a structured environment.

---

## ✨ Features

### 👤 User Features

* User Registration & Login (Authentication)
* Create and Join Projects
* Real-time collaboration with team members
* Task creation and management
* Responsive user interface

### 🛠 Admin / System Features

* Project and user management
* RESTful API integration
* Scalable backend architecture

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/inspiron76/Project-mgmt-backend.git
cd Project-mgmt-backend
```

---

### 2️⃣ Backend Setup (Spring Boot)

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

---

### 3️⃣ Frontend Setup (React)

```bash
cd frontend
npm install
npm start
```

---

## 🔗 API Endpoints (Sample)

* `POST /api/auth/register` → Register user
* `POST /api/auth/login` → Login user
* `GET /api/projects` → Fetch projects
* `POST /api/tasks` → Create task
